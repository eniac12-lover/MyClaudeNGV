## C. 점검 메모 (스킬 `references/traceability.md` §2.4 절차 적용)

- **빈 다운스트림 컬럼(갱신, Rev 1.1)**: A절/A.1절 전체 행의 Architecture 컬럼은 이번
  개정(`SWA-001`)에서 채워졌다. Detailed Design~SWE.6는 여전히 공란 — 상세설계/구현/시험
  단계 착수 전이므로 정상이며, 다음 단계(`detailed-design` 스킬)에서 **새 행을 추가하지
  않고 기존 행을 찾아** Detailed Design 컬럼을 채워야 한다.
- **Coverage 갱신(Rev 1.1)**: A절 11개 SWR 행 + 9개 인터페이스 행 = 20행 모두 "계획"→
  "진행중(아키텍처 반영, SWA-001)"으로 갱신(여전히 검증 미완료). B절 8행은 "미착수"를
  유지하되 Architecture 열에 SWA-001이 확보한 컴포넌트 자리(DES-nnn, 상세 로직 미구현)를
  선반영했다.
- **Detailed Design/Code 열 갱신(Rev 1.2)**: A절 11행 + A.1절 9행 = 20행 전체의
  `Detailed Design`(`UNIT-nnn`)과 `Code`(예정 소스 경로, `src/childlock/...`) 컬럼을
  `SWD-001_SW상세설계서`(2026-09-18)를 근거로 채웠다(Coverage도 "진행중(상세설계 반영,
  SWD-001)"로 갱신). B절 8행 중 DES-018~022(Phase2 규칙 스텁)에 해당하는 6행은 UNIT-nnn과
  예정 경로를 기입했으나 Coverage는 "미착수"를 유지했다(로직이 없는 무결정 스텁만
  상세설계했기 때문 — SWA-001 §9.2 통합순서 13단계 근거). DES-015(DisplayQueryService)에
  해당하는 2행은 `SWD-001`이 명시적으로 Phase3 제외 대상으로 선언했으므로 Detailed Design
  열을 공란으로 유지했다.
- **파생 컴포넌트(전용 행 없음, Rev 1.2 확인)**: `OutputStateRepository`(UNIT-011),
  `RulePriorityRegistry`(UNIT-012), `HoldLastOutputRule`(UNIT-016),
  `ArbitrationOrchestrator`(UNIT-017)는 SWA-001 §8.2가 이미 "파생 — 상위 SWR ID 없음"으로
  표기한 컴포넌트(DES-005/006/010/011)에 대응하며, 본 매트릭스에 전용 행이 없으므로 새
  행을 추가하지 않고 `SWD-001` §12/§14.2에서만 추적한다.
- **끊어진 링크**: 없음 — SWR-001 문서에 등장하는 모든 SWR ID와 모든 OEM-IF-001~009가
  A절/A.1절에 등록되어 있고, SWA-001의 DES-001~022 전체가 A절/A.1절/B절 중 최소 1곳에
  등장한다(고아 설계요소 없음 — SWA-001 §8.2 요구사항 배분표와 상호 대조 완료).
- **고아 산출물**: 없음(코드/테스트 산출물은 아직 없음 — `SWD-001`은 예정 경로만 기입했고
  실제 소스 파일은 `coding` 단계에서 생성된다).
