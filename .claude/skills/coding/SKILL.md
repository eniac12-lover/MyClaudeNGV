# 구현(Coding) 스킬

`CLAUDE.md`의 "구현 지침"을 준수해 상세설계 산출물을 실제 코드로 구현하는 절차입니다. `detailed-design`의 산출물을 계약으로 삼고, `tdd` 스킬의 Red-Green-Refactor 방법론으로 구현하며, 아래 품질 지표를 오픈소스 도구로 검증합니다.

> 품질 지표 수치(라인수 50, 복잡도 10, 중복 7라인, 주석 20%, 3글자 이상 camelCase)는 `CLAUDE.md` "구현 지침"에 명시된 프로젝트 고유 기준입니다. 표준 원문이 아니라 프로젝트 정책이므로, 이 스킬이나 `CLAUDE.md`가 바뀌면 그에 맞춰 갱신하세요.

## 0. 입력 확인

구현 대상 단위(`UNIT-nnn`)와 그 함수 계약을 `detailed-design`의 산출물(§5 핵심 함수 계약, §6 알고리즘, §7 결정표, §8 상태전이, §10 오류/방어동작)에서 확인합니다. 계약이 없으면 먼저 `detailed-design`을 수행하거나 사용자에게 계약 정보를 확인합니다. **계약에 없는 동작을 임의로 추가하지 않습니다** — 계약과 다르게 구현해야 할 이유가 있으면 조용히 바꾸지 말고 사용자에게 보고합니다.

## 1. 개발 환경/언어

- Python 3.14로 작성합니다.
- 테스트는 `unittest`로 작성합니다(다른 테스트 프레임워크로 대체하지 않습니다).

## 2. TDD로 구현

**가장 먼저** `Skill` 도구로 `tdd` 스킬을 로드하고, 그 Red-Green-Refactor 절차를 그대로 따릅니다. 이 스킬의 절차를 다시 서술하지 않습니다 — `tdd` 스킬이 유일한 개발 방법론 출처입니다.

## 3. 품질 게이트 (Refactor 단계마다, 그리고 단위 완료 시 필수)

`references/quality-metrics-tools.md`의 오픈소스 도구 명령을 실행해 아래를 **반드시** 만족시킵니다. 하나라도 위반하면 다음 단위로 넘어가지 말고 리팩터링합니다.

| 지표 | 기준 | 도구 |
|---|---|---|
| 함수 순수코드라인(주석/공백 제외) | ≤ 50줄 | `lizard` (NLOC) |
| 함수 순환복잡도 | ≤ 10 | `lizard` (CCN) |
| 중복 코드 | 7줄까지 허용(8줄 이상 중복 금지) | `pylint` similarity checker |
| 주석 비율 | ≥ 20% | `radon raw` 기반 계산 |
| 함수/변수명 | 3글자 이상, camelCase | `pylint` naming 설정 |

정확한 실행 명령과 결과 해석 기준은 `references/quality-metrics-tools.md`를 참고하세요.

## 4. Doxygen 주석 작성

`references/doxygen-comments.md`의 형식(`\brief`, `\param`, `\return`, `\throws`)으로 모든 공개 함수/클래스에 주석을 작성합니다. 주석은 함수 계약(§0)의 사전/사후조건·예외를 그대로 옮겨 적어 계약과 문서가 어긋나지 않게 합니다.

## 5. 네이밍 규칙

`references/naming-conventions.md`에 따라 함수명·변수명을 3글자 이상, camelCase로 작성합니다. 약어나 한 글자짜리 임시 변수(`i`, `x` 등 반복문 인덱스 제외)를 피합니다.

## 6. 추적성

`requirements-analyst`의 `references/traceability.md` §0에 정의된 공식 매트릭스(`TPL-TRC-001_...xlsx`)에서 해당 `UNIT-nnn` 행을 찾아 `Code` 컬럼에 실제 소스 파일 경로/함수명을 채웁니다. 테스트가 작성되면 (SWE.4 스킬이 아직 없으므로) `SWE.4` 컬럼에 잠정적으로 테스트 ID나 테스트 파일 경로를 기록하고, 향후 SWE.4 전용 스킬이 생기면 그쪽에서 정식으로 관리하도록 인계합니다.

## 7. 출력 및 자체 점검

구현을 마치면 다음을 요약해 보고합니다: 구현한 단위와 대응 함수 계약, TDD 사이클 수행 여부(각 동작별 Red 확인 여부), 품질 게이트 5개 지표의 실제 측정값과 통과 여부, Doxygen 주석 비율, 추적성 매트릭스 갱신 여부, 계약과 다르게 구현한 부분이 있다면 그 사유.
